# KNOWBEYONDME

A cinematic personal journey. Journey still being written.

**Phase 2** is the opening experience. Phase 1 engine test remains at `/?engine=test`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What you should see

A full-viewport test environment with three placeholder scenes (A → B → C). Scroll to move through the journey. This is not the final experience.

## Debug (development only)

- Add `?debug=1` to the URL
- Or press `Ctrl+Shift+J`
- Or set `NEXT_PUBLIC_JOURNEY_DEBUG=true` in `.env.local`
